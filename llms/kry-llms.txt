# KRY (Livi)

> KRY is a Swedish digital healthcare provider headquartered in Stockholm, operating internationally under the Livi brand. It delivers primary care through video and chat consultations with doctors, nurses, psychologists, physiotherapists, dietitians and midwives via its iOS and Android apps, and also runs physical primary care centres, child health clinics and midwifery clinics across Sweden. KRY publishes no public developer program, partner API, SDK or MCP server — the platform is consumer- and clinician-facing.

## API surface

KRY has no public API. As of 2026-07-19 there is no developer portal, no API reference, no OpenAPI or AsyncAPI document, no SDK or package on npm/PyPI/Maven/NuGet/RubyGems, no CLI, no MCP server, no webhook catalog, and no `/.well-known/` discovery documents on any of the four brand hosts (kry.se, kry.no, livi.co.uk, livi.fr) — every probed path returned 404. Integrations with pharmacies, regions and partner providers are handled through private commercial agreements rather than a published developer program.
